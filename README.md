# TaskMaster 📋

TaskMaster is an Android task management application developed using Kotlin and Android Studio. It allows users to create, manage, search, filter, complete, and delete tasks.

## Features

- ✅ Add new tasks
- ✅ Edit existing tasks
- ✅ Mark tasks as completed
- ✅ Delete tasks
- ✅ Search tasks
- ✅ Filter tasks by All, Completed, and Pending
- ✅ Local task storage using Room Database
- ✅ Firebase Firestore synchronization
- ✅ Firebase Authentication
- ✅ Login and account creation
- ✅ Automatic login session checking
- ✅ Simple and user-friendly interface

## Technologies Used

- Kotlin
- Android Studio
- Android SDK
- XML
- RecyclerView
- Room Database
- Firebase Authentication
- Firebase Cloud Firestore
- Material Design
- Coroutines
- Retrofit
